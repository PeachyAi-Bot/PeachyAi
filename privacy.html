Privacy Policy

Last updated: 11 October 2026

What information PeachyAI collects

Each server can have one selected chat channel. When a server administrator selects a channel with /memoryenable, PeachyAI may store qualifying messages from that channel, along with the message time, server and channel IDs, the author's user ID, and display name. Selecting another channel moves PeachyAI's chat features to that channel.

When you mention PeachyAI, it may store your prompt and the bot's reply, together with your user ID, the server and channel IDs, and the time. It may also store saved memories: their text, category, associated user and server IDs, display name, and creation or update times. Memories can be added at a user's request or created from eligible channel messages when automatic memory creation is enabled.

PeachyAI also stores the selected chat channel for each server. If you opt out, it stores your Discord user ID and opt-out time. The bot does not save direct-message content.

How PeachyAI uses information

Channel messages help generate automatic channel replies and /gen text. Mention prompts, conversation history, and saved memories help PeachyAI respond to you.

In the selected chat channel, PeachyAI sends eligible messages to Mancer to extract useful details, such as interests or preferences. PeachyAI may save those details as memories and use them to personalize later replies. Mancer's handling of messages sent to its API is described in Mancer's Privacy Policy.

How saved memories work

  1. A server administrator selects one chat channel with /memoryenable.
  2. PeachyAI sends eligible messages from that channel to Mancer, which extracts useful details.
  3. PeachyAI may save those details as memories associated with the relevant user and server.
  4. PeachyAI can use saved memories as context for later replies. Memories are automatically deleted after seven days.

This process saves information for PeachyAI to use in replies; PeachyAI's code does not use those messages to train or fine-tune the AI model.

Services that process information

  • Mancer AI: PeachyAI sends relevant prompts, message context, and saved memories to Mancer through its API to generate replies. Eligible channel messages may also be sent to extract details for saved memories. See Mancer's Privacy Policy.
  • PebbleHost: PeachyAI is hosted on PebbleHost. See PebbleHost's Privacy Policy.

Mention replies, automatic channel replies, and successful /gen results are posted in their server channels and can be seen by members who can view those channels. Other slash command responses are private.

How long information is kept

PeachyAI automatically deletes saved messages, memories, and mention history after seven days. The selected chat channel remains set until changed with /memoryenable or disabled with /memorydisable. This schedule applies to data held by PeachyAI; Discord and Mancer handle information they receive under their own privacy policies.

When PeachyAI leaves or is removed from a server, it deletes its stored messages, memories, mention history, and channel settings associated with that server. This does not delete the same users' data associated with other servers or their opt-out records, or automatically remove information already processed by Discord or Mancer.

Request deletion: Email peachyai-privacy@proton.me with your Discord user ID or server ID and describe what you want removed.

Why the opt-out record is kept

PeachyAI keeps your user ID and opt-out time so it can recognize and honor your opt-out across servers after deleting your other saved records. This marker is not message or conversation history. /optin removes it.
